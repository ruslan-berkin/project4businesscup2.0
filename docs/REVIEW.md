## Фактические проверки

- В отдельном виртуальном окружении установлены зависимости из обновлённого `requirements.txt`.
- 16 тестов Python проходят. Включены 8 кампаний × 2 языка × 3 финала, предметы, пользовательское действие, смерть, бесконечный режим, имитации ответов OpenAI, XLSX, восстановление одиночного `app.py`, ошибочные запросы и health-check.
- Проверка Gunicorn `--check-config` проходит.
- Тест вычисления формул работает с фактической функцией из `app.js`, без дублирования её реализации.
- `pip-audit` после обновления: известных уязвимостей не найдено. Это результат доступной базы аудита на момент проверки, а не гарантия отсутствия любых уязвимостей.
- Поиск распространённых сигнатур ключей OpenAI, GitHub и Google по объектам истории Git не нашёл совпадений. Проверка ограничена этими шаблонами; содержимое локального `.env` в отчёт не включается.
- Предыдущие проверки интерфейса, Esc, сохранения рабочих правок и задержанного ответа описаны в [VERIFICATION.md](../tabescape_app/VERIFICATION.md). Они не выдаются за новый полный браузерный прогон этого ревью.

## Автоматизация на GitHub

Workflow `CI` запускается на push в main, pull request и вручную. Проверяются Python 3.11/3.12, истории и восстановление ресурсов, Gunicorn, синтаксис JavaScript, формулы и зависимости. Действия закреплены по commit SHA; workflow имеет только чтение содержимого и не получает рабочие API-ключи. Фактический результат каждого запуска доступен во вкладке Actions.

## Что остаётся до коммерческого запуска

- Подключить и проверить реальный OpenAI: ответы сейчас проверены через имитации. Длинные партии требуют отдельной оценки связности и стоимости.
- Реализовать платежи, серверную проверку подписки и контроль расходов/частоты ИИ-запросов. Сейчас Premium — открытое демо.
- Опубликовать Flask-приложение и добавить проверенную ссылку; подготовить PDF-презентацию.
- Выбрать лицензию после подтверждения прав на предоставленные изображения.
- При развитии проекта разделить монолитные `app.py` и `app.js`, заменить вычисление формул полноценным ограниченным парсером и отдельно проверить крупные/сложные книги.
- Для длительных партий добавить сохранение на сервере или явный экспорт/импорт партии. Сейчас она живёт только в текущей вкладке.

История Git не переписывалась. Репозиторий не переименовывался; действующие ссылки сохраняются.
