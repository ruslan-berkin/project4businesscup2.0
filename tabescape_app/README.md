# TabEscape

Flask + обычный JavaScript. Одна процедурная RPG про Оукхейвен в четырёх офисных интерфейсах. Основной путь работает без регистрации, своего файла и ключа ИИ.

## Запуск

Из каталога tabescape_app:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть http://localhost:5000. Если порт занят на macOS, выполнить `PORT=5050 python app.py` и открыть http://localhost:5050.

Для хостинга:

```sh
gunicorn app:app --bind 0.0.0.0:8000
```

В корне репозитория есть render.yaml с rootDir=tabescape_app, установкой зависимостей и запуском Gunicorn. После входа в Render создайте Blueprint из этого репозитория. Публичный адрес появляется после успешного развёртывания.

## Сценарий

На старте выбрать язык и Excel, Word, Outlook либо AutoCAD. Все варианты продолжают одну партию. Excel сохраняет исходную сетку, журнал с графиком, инвентарь и редактирование книг. Остальные маски показывают сюжет, действия, показатели, инвентарь и историю через общий движок.

Esc или кнопка в верхней панели открывает рабочий экран. Повторное переключение возвращает игру. При открытых настройках Esc закрывает настройки. В строке формул Esc отменяет ввод. Удержание Esc не вызывает повторного переключения.

Обучение включает настоящий ход и проверку переключения туда и обратно. Его можно пропустить или повторно открыть через «Как играть». Повторное обучение сохраняет текущую партию.

Рабочие данные:
- Excel — локальная заполненная книга static/data/Книга1.xlsx с листом Q4_Прогноз. При ошибке чтения доступен встроенный прогноз. Открытый пользователем файл или созданная книга имеют приоритет.
- Word — редактируемый документ.
- Outlook — три локальных письма с отдельной областью чтения.
- AutoCAD — браузерный план помещений, масштаб и слой мебели.

Импорт поддерживает .xlsx, .csv, .tsv и .txt (табличный текст). Старый бинарный .xls не поддерживается. Экспорт формирует .xlsx. Формулы поддерживаются в объёме существующего движка: арифметика, ссылки, диапазоны, SUM/СУММ, AVERAGE/СРЗНАЧ, IF/ЕСЛИ, MIN/MAX, ROUND, COUNT, ABS. Для неподдерживаемых формул импортированный файл может отображать сохранённое Excel значение.

Выбранная маска, язык, обучение и рекорд сохраняются в localStorage. Сама партия и рабочие правки живут в текущей вкладке до перезагрузки. Файлы читаются браузером, при экспорте исходная книга и правки передаются Flask-серверу.

## Локализация

English переключает старт, обучение, основные команды и названия показателей. Процедурный сюжет, варианты действий, инвентарь и старые меню Excel остаются русскими. Рабочие демонстрационные документы англоязычные. Название вкладки и значок соответствуют текущей маске.

## Ресурсы и резервное восстановление

Канонические файлы находятся в templates/ и static/. После их изменения выполнить:

```sh
python scripts/embed_assets.py
python -m unittest discover -s tests -v
```

Скрипт обновляет _EMBEDDED_FILES в app.py, включая портреты и книгу. Тест сравнивает байты и запускает копию одного app.py в пустом каталоге, проверяя восстановление актуального интерфейса. Восстановление выполняется при запросе / и работает также с Gunicorn.

Портреты проводниц скопированы из предоставленных командой референсов. Перед публичным продвижением команда должна подтвердить право их использования.

## Продуктовые ограничения

ИИ опционален и настраивается через исходные параметры героя или переменные окружения из .env.example. Проверки проводились без ключей. AutoCAD представляет интерактивный браузерный план, импорт DWG отсутствует.

Сохранена исходная механика штрафа за повторный выбор одинакового номера кнопки. Это может снизить здоровье даже при выборе спокойного действия. Для живого показа читайте варианты и меняйте выбранную позицию.

## Обновление интерфейса и демо Plus

Верхняя панель сворачивается кнопкой «Скрыть панель». Компактные кнопки позволяют вернуть её и переключить Esc. Настройка сохраняется в браузере.

Word получил отдельную ленту, страницу документа, строку состояния, форматирование выделенного текста (полужирный, курсив, подчёркивание) и размер текста документа. Рабочие правки сохраняются в текущей сессии.

Демо позволяет играть бесплатно без ограничений. После третьего завершённого приключения за локальный календарный день проводница показывает предложение будущей подписки Plus. «Продолжить бесплатно» сразу начинает следующую партию. Закрытие окна позволяет просмотреть финал. Счётчик в localStorage нужен только для показа предложения один раз в день и никогда не блокирует запуск, включая браузеры с ранее исчерпанным лимитом. Завершением считается победа или поражение.

Это демонстрационное предложение подписки без ограничения доступа. Для платного продукта потребуется серверный учёт пользователей и подписок. OpenAI-генерация сюжетов, выбор жанров, бесконечный режим и приём платежей запланированы. Кнопка подписки сейчас показывает информацию о будущем запуске.

Word использует полноширинную тёмную ленту и центрированную страницу. При выборе этой маски панель TabEscape скрыта; кнопка «•••» в левом верхнем углу открывает её. Размер шрифта указан в пунктах. Документ можно редактировать и скачать в HTML через значок сохранения; изменения рабочего документа сохраняются в текущей вкладке при переключениях Esc.

## Интерфейс из TabEscape (2).html

Главная страница Flask теперь использует новый иллюстрированный экран выбора, Миру, обучение и адаптивные рабочие интерфейсы из загруженного HTML. Разметка, стили, обучение, локализация и изображения вынесены в `templates/index.html`, `static/css/style.css`, `static/js/{app,assets,office-i18n,tour}.js` и `static/images/`. Корневой HTML остаётся самостоятельным референсом; последующие правки сайта нужно вносить в эти рабочие файлы.

Браузерный `localAdventure` из автономной версии удалён из обслуживаемой страницы. Новая игра и ход вызывают существующие Flask API. Английские тексты сцен взяты из загрузки и подключены к тем же серверным правилам через `static/data/story-en.json`; русский сценарий сохранён. Книга загружается из `/api/workbook/default`, а экспорт использует `/api/export_xlsx`, сохраняя исходное OOXML-оформление импортированной книги. Дополнительный Groq/Gemini-ключ доступен в раскрываемом блоке настроек, основной сценарий работает без ключей.

После изменения ресурсов запустите `python scripts/embed_assets.py`, чтобы обновить резервную встроенную копию. Команды запуска остаются `python app.py` и `gunicorn app:app`.
