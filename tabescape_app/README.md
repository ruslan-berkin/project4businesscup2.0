# TabEscape

Flask + обычный JavaScript. Восемь бесплатных историй, четыре офисных интерфейса и демонстрация Premium / бесконечного режима. Основной путь работает без регистрации, загрузки своего файла, оплаты и ключа ИИ.

## Локальный запуск

Из корня репозитория:

```sh
cd tabescape_app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

Открыть [localhost:5050](http://localhost:5050). Без `.env` используется порт 5000; изменить его можно через `PORT=5050 python app.py`.

На хостинге из `tabescape_app`:

```sh
gunicorn app:app --timeout 60 --bind 0.0.0.0:8000
```

Корневой `render.yaml` задаёт `rootDir`, зависимости, Gunicorn и постоянный секрет подписи. Действующая публичная версия: [tabescape.onrender.com](https://tabescape.onrender.com/). Сам GitHub Flask не запускает.

### Автоматические обновления

В `render.yaml` выбран `autoDeployTrigger: checksPass` для ветки `main`. Для работы автообновлений аккаунт GitHub должен быть подключён к Render с доступом к `ruslan-berkin/project4zimran`: одного публичного URL репозитория недостаточно.

После push или merge в `main` GitHub Actions запускает проверки. При их успешном завершении Render собирает изменения внутри `tabescape_app` и публикует их по прежнему адресу. При неуспешной сборке продолжает работать предыдущая версия. Изменения только корневой документации не запускают сборку приложения. Состояние публикации видно в **Render → tabescape → Deploys**.

После изменений шаблона или статики перед коммитом выполните `python scripts/embed_assets.py` из `tabescape_app`: CI проверяет актуальность встроенной резервной копии. После успешной публикации обновите вкладку сайта, чтобы загрузить новый интерфейс. Ключи остаются в **Render → Environment**; локальный `.env` при push не переносится.

Для проверки конкретного обновления сравните SHA коммита в GitHub с **Last successfully deployed commit** в Render. Статус успешного CI означает, что тесты прошли; публикация завершена только после статуса **Live** у того же коммита.

## Начало партии

Выбор **любого** интерфейса — Excel, Word, Outlook, AutoCAD — открывает окно подготовки. `/api/start` вызывается только после кнопки «Начать игру». В окне доступны:

- Новая игра или продолжение сохранённой партии в том же браузере после перезагрузки. Продолжение не отправляет ход и не перезапускает движок.
- Бесплатная история, Premium-сюжет или бесконечный режим; жанр для последних двух.
- Отдельная галочка обучения с Мирой.
- В Excel — необязательная загрузка рабочей книги. В остальных масках уже подготовлены документ, письма или чертёж.

Esc закрывает окно подготовки. Импорт книги сначала подготавливается: отмена окна не применяет черновик. Ошибка чтения оставляет прежнюю книгу или готовый отчёт.

## Бесплатная библиотека

| История | Жанр |
|---|---|
| Оукхейвен: тихий колокол | Сдержанное фэнтези |
| Строка 17 | Детектив |
| Смотритель последнего маяка | Мистика |
| Шестая палата | Хоррор |
| Орбита без связи | Научная фантастика |
| Перевал до снегопада | Экспедиция |
| Письмо через осаду | Историческое приключение в вымышленном мире |
| Последний поезд | Триллер |

Каждая история обычно занимает шесть выборов. Есть два маршрута расследования, сбор сведений, предмет и три финала: разрешение конфликта, компромисс и уход. Итог зависит от собранных сведений, а рискованные действия могут привести к поражению раньше. Свой ход и использование предмета тоже занимают ход. Это короткие авторские истории; история и действия полностью переведены на русский и английский.

Новый Оукхейвен заменяет прежнюю солнечную ярмарку тайной колокола и спором за воду. Общий тон — надежда и неопределённость, без чрезмерной сказочности и без постоянной безысходности. Ландшафт на главной приглушён. Хоррор выделен отдельным жанром.

Каждый ход добавляет 30 игровых минут, но **18:00 больше не завершает новую кампанию**: её завершает сюжет либо состояние героя. В обычных режимах поражение наступает при нулевом здоровье/бодрости или 100% неприятностей. В бесконечном режиме нулевая бодрость или 100% неприятностей отнимают здоровье; финал наступает только при нулевом здоровье. Часы продолжаются через полночь. Штрафа за повторное нажатие одного номера варианта в новых кампаниях нет.

Сюжет и правила находятся в `static/data/campaigns.json`, каталог — `/api/catalog`. Новые партии используют существующие `/api/start` и `/api/action`. Сервер подписывает состояние, включая показатели, инвентарь и память истории. Старый API без `mode/campaign_id` оставлен для совместимости; интерфейс всегда использует новые кампании.

## Premium и ИИ

Сейчас все режимы доступны **как демо без подписки**. После третьего завершения за локальный календарный день Мира предлагает будущий Plus. Окно можно закрыть или продолжить бесплатно; оно не блокирует игру. Оплата, аккаунты и проверка подписки ещё не подключены.

При `AI_ENABLED=false` или пустом ключе:

- Free — восемь авторских историй.
- Premium — авторская история выбранного жанра с явной подписью «демо без ИИ».
- Endless — повторяемые локальные главы выбранного жанра до гибели героя, также явно обозначенные как демо. Это не генерация новых сюжетов.

Чтобы подключить Groq, заполнить **только серверный** `tabescape_app/.env` по примеру:

```dotenv
AI_PROVIDER=groq
AI_ENABLED=true
GROQ_API_KEY=ваш_ключ_Groq
GROQ_MODEL=openai/gpt-oss-20b
TABESCAPE_SECRET_KEY=ваш_постоянный_случайный_секрет
PORT=5050
```

Секрет подписи создать один раз:

```sh
python -c 'import secrets; print(secrets.token_hex(32))'
```

После изменения окружения перезапустить сервер и обновить страницу. На хостинге задать эти же переменные в настройках сервиса. `.env` исключён из Git. Примеры есть и в корне репозитория, и рядом с `app.py`. Без постоянного секрета используется временный ключ процесса: партия не переживает перезапуск сервера; для нескольких workers обязательно задать постоянный секрет.

Ключ не передаётся в браузер. Groq использует [Chat Completions](https://console.groq.com/docs/api-reference) со [strict Structured Outputs](https://console.groq.com/docs/structured-outputs). Модель по умолчанию — `openai/gpt-oss-20b`; несмотря на имя модели, она работает на Groq и требует ключ из [Groq Console](https://console.groq.com/keys). При изменении `GROQ_MODEL` нужна поддержка strict JSON Schema.

Альтернативно задайте `AI_PROVIDER=openai`, `AI_ENABLED=true`, `OPENAI_API_KEY` и `OPENAI_MODEL=gpt-5-mini`: используется существующий OpenAI Responses API. `AI_ENABLED` имеет приоритет; если его нет, читается прежний `OPENAI_ENABLED`. Автоматическое переключение при HTTP 401/403/429/5xx включается только через `AI_FALLBACK_PROVIDERS`; пример Groq → Gemini есть в основном README. После смены провайдера начните новую партию: существующая сессия привязана к разрешённому движку. Бесплатный режим не вызывает ни один из этих API даже при включённом ключе.

Каждый запрос содержит жанр, завязку, героя и наставника, показатели, инвентарь, последние четыре сокращённых события и обновляемое моделью резюме истории. Модель развивает конфликт и последствия выбора. Premium запрашивает завершённую арку примерно на 25–30 ходов (это ориентир для модели, не жёсткий лимит). Endless разрешает локальные развязки и новые главы, но сервер игнорирует сигнал окончательного финала, пока герой жив. Ошибка/таймаут не применяет ход: его можно повторить. Запросы к OpenAI используют `store:false`; подписанное состояние игры сохраняется в браузере после подтверждённого хода.

Качество длинных ИИ-партий требует отдельного игрового тестирования. До коммерческого публичного запуска понадобятся платежи, серверная проверка доступа, ограничение расходов/частоты запросов и измерение качества длинных партий. Сейчас включение API делает генерацию доступной участникам демо, без оплаты.

## Рабочие экраны и сохранение

Esc и экранная кнопка переключают игру и работу в той же вкладке, без запросов к игровому API. Поздний ответ хода обновляет игру и отображается после возврата. Во время работы сюжет, проводница и игровые показатели скрыты. В настройках Esc закрывает диалог, в строке формул отменяет ввод; удержание клавиши не переключает экран многократно.

- Excel: заполненная `static/data/Книга1.xlsx`, при ошибке чтения — встроенный Q4-прогноз. Открытая/созданная пользователем книга приоритетна. Импорт `.xlsx`, `.csv`, `.tsv`, `.txt`; бинарный `.xls` не поддерживается. Редактирование, листы, стили, формулы и экспорт `.xlsx` сохранены. Формулы: арифметика, ссылки, диапазоны, SUM/СУММ, AVERAGE/СРЗНАЧ, IF/ЕСЛИ, MIN/MAX, ROUND, COUNT, ABS. Неподдерживаемые импортированные формулы могут показывать кэш Excel.
- Word: тёмная лента, редактируемый документ, форматирование и скачивание HTML.
- Outlook: локальные письма и область чтения.
- AutoCAD: браузерный чертёж, масштаб и слой мебели; импорта DWG нет.

Маски показывают одну текущую партию; смена оформления не меняет выбранный сюжет. Журнал, график здоровья, инвентарь, собственный ход, рекорд, настройки героя, повторная игра и выгрузка дневника сохранены.

При новом открытии сайта кнопка запуска и обучение по умолчанию выбирают Excel. В текущей вкладке сохраняется выбранная маска. Язык, обучение, скрытие панели и рекорд сохраняются в localStorage. **Партия, журнал и инвентарь сохраняются после хода в localStorage. После перезагрузки выберите «Продолжить»; `/api/resume` проверяет подпись без хода и запроса к ИИ. Рабочие правки живут только до перезагрузки**. Для сохранений между перезапусками сервера необходим постоянный `TABESCAPE_SECRET_KEY`. Очистка данных браузера удаляет сохранение. Загрузка Excel — рабочий документ, не сохранение партии.

## Ресурсы и проверка

Рабочие файлы — `templates/` и `static/`; корневой `TabEscape (2).html` остаётся самостоятельным референсом. После изменения ресурсов:

```sh
python scripts/embed_assets.py
python -m unittest discover -s tests -v
```

Скрипт обновляет `_EMBEDDED_FILES` в `app.py`, включая библиотеку, изображения и книгу. Тест проверяет идентичность ресурсов и запуск одного `app.py` в пустой папке с восстановлением текущего интерфейса. Серверные тесты проверяют все кампании/финалы на двух языках и Groq/OpenAI на имитации ответов без расходов. Фактические проверки браузера описаны в `VERIFICATION.md`.

RU/EN доступны для старта, окна игры, библиотеки, всех новых сцен/действий/финалов, обучения, основных команд и показателей. Демонстрационные рабочие документы преимущественно английские. Ресурсы проводницы предоставлены командой; права на публичное распространение подтверждает команда.
